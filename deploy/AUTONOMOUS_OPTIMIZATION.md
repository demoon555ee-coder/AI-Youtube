# Autonomous Optimization

The v3.7 optimizer combines post-publish anomalies, creative analysis and the multimodal production graph into one bounded decision.

Supported scopes:
- `scene_reedit`
- `packaging_experiment`
- `blueprint_replan`
- `full_rebuild`
- `no_action`

A decision is observational: it records evidence and a hypothesis. It does not mutate a published source in place. Execution remains behind the existing content-write permission and Quality Gate.
